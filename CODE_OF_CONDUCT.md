# Code of conduct

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless
of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity
and expression, level of experience, education, socio-economic status, nationality, personal
appearance, race, caste, colour, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.
- Take responsibility for mistakes and learn from them.

## Unacceptable behaviour

- Sexualised language or imagery, and unwelcome advances.
- Trolling, insults, derogatory comments, and personal or political attacks.
- Public or private harassment.
- Publishing others' private information without their explicit permission.
- Any other conduct that would be inappropriate in a professional setting.

## Scope and enforcement

This code applies in all project spaces: issues, pull requests, discussions and reviews. It also
applies when someone represents the project in public.

Report unacceptable behaviour privately to the maintainer, [@JawadulHadi](https://github.com/JawadulHadi),
using the contact details on their GitHub profile. Reports are reviewed promptly and kept
confidential. The maintainer may remove, edit or reject contributions, and may temporarily or
permanently ban anyone whose behaviour breaks this code.
